# Pesquisa de Satisfação — Atendimento ao Cliente
 Empresa: TudoWeb
 Aluna: Simone Araujo
 ## 📋 Sobre o Projeto
 Programa em Python que coleta a opinião de clientes sobre o atendimento, com:
 - ✅ Teste com 10 entrevistados
 - ✅ Versão final com 50 entrevistados
 ## 🛠️ Comandos Utilizados
 - for i in range() → repetição para cada entrevistado
 - while + and → validação da opinião (só aceita 1, 2 ou 3)
 - if / elif / else → contagem das respostas
 - input() → entrada de dados: nome, idade e opinião
 ## 📊 Resultados Exibidos
 - Quantidade de respostas *EXCELENTE*
 - Quantidade de respostas *RUIM*
